Photo Caliper - ชุดภาพ COLMAP (ประมวลผลบน PC)

1) ติดตั้ง COLMAP เวอร์ชัน CUDA สำหรับ Windows (github.com/colmap/colmap/releases)
   แตกไฟล์ไว้ที่ C:\COLMAP  และติดตั้ง Python 3 (python.org, ติ๊ก Add to PATH)
2) แตก colmap_set.zip ไว้ในโฟลเดอร์ใดก็ได้ (ห้ามมีอักษรไทยใน path จะดีที่สุด)
3) ดับเบิลคลิก run_colmap.bat  (GTX 1650: 30 ภาพ ~15–40 นาที)
4) ผลลัพธ์: dense\meshed-poisson_mm.ply (เมช หน่วยมม.) และ dense\fused_mm.ply (จุด)
   scale.json = สเกลที่ใช้ (spread % ยิ่งน้อยยิ่งดี; >3% ควรตรวจภาพที่มีมาตราวัด)
5) เปิดไฟล์ _mm.ply ในแท็บ 3D ของแอป เพื่อวัดระยะ/รอบวง/ปริมาตร

เคล็ดลับ: ถ่ายรอบวัตถุ 20–40 ภาพ ซ้อนกัน 60–80% แสงสม่ำเสมอ ไม่ใช้แฟลช
วัตถุผิวมัน/ไม่มีลาย จะได้ผลแย่ — ใส่มาตราวัดอย่างน้อย 3–5 ภาพ
ข้อมูลทุกอย่างอยู่ในเครื่องของคุณ ไม่มีการอัปโหลด
